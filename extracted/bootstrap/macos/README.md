# macOS app-local toolchain

On a supported Mac, double-click `launch-gui-macos.command` to open the patcher in Terminal. You can also run `bootstrap/macos/launch-gui-macos.sh` from Terminal. Both expect `eaglercraft-26.2-u1-patcher-gui.jar` in the package's top-level directory. The bootstrap installs Java 17, Java 25, Node.js 24 LTS, and npm under `.toolchain/`, then writes UTF-8 `toolchain.properties` beside the GUI JAR. The `npm` property points to Node's `npm-cli.js`.

Supported hosts are macOS 13 Ventura or newer on Intel x86_64 and Apple Silicon arm64. Matching Node.js 24 and Eclipse Temurin 17/25 archives and official SHA-256 sources were checked for these architectures. Unsupported OS versions and architectures fail before creating or changing the app directory. Run as a normal user. The scripts use macOS `curl`, `tar`, and `shasum`; they do not use `sudo`, run a `.pkg` installer, install system packages, change `PATH`, or write outside the app directory. Downloads are several hundred megabytes. Allow extra space for temporary and extracted files.

Each install fetches current release metadata over HTTPS. Java archive URLs must match the requested official Eclipse Temurin macOS JDK architecture, and the API SHA-256 must match the release's `.sha256.txt` sidecar. The Node.js 24 LTS archive is checked against `nodejs.org`'s `SHASUMS256.txt`. Before extraction, the bootstrap rejects archive members or link targets with absolute or escaping paths. It publishes the toolchain manifest with an atomic rename after Java, Node, and npm run successfully. A per-app lock directory serializes simultaneous launchers and recovers a same-host lock left by a dead process.

This bootstrap installs build tools only. You must provide the official Minecraft 26.2 client JAR and the patcher's other authenticated inputs. It does not install Xcode tools, acquire media, grant redistribution rights, build the game, sign or notarize the package, or deploy it. Rights for the official JAR, media, and third-party materials remain separate requirements.

To run the offline contract test on macOS or Linux, use `sh bootstrap/macos/test-bootstrap-macos.sh`. It uses fake vendor metadata and small fixture archives; it does not download real toolchains. Linux can check the shell contract with mocked `uname` and `sw_vers`, but cannot verify native macOS execution or archive compatibility. Test on a Mac before describing this launcher as tested on macOS.
